# Support

AIK is an experimental open-source project maintained on a best-effort basis.

## Questions and usage help

Before opening an issue:

1. read the README and the relevant file under
   `.agents/skills/improve-agent/references/`;
2. run `python aik.py --help` and `python aik.py validate CASE_DIR`;
3. search existing GitHub issues.

If the problem remains, open a bug report or feature request using the repository's
issue forms. Include a minimal synthetic reproduction, AIK version, Python version,
operating system, and the exact command. Redact agent conversations and generated
artifacts before attaching them.

## Security and sensitive data

Do not put vulnerabilities, credentials, private prompts, customer data, or internal
agent traces in a public issue. Follow [SECURITY.md](SECURITY.md) instead.

## What is not provided

There is currently no service-level agreement, hosted service, paid support channel,
or guarantee of backward compatibility before `v1.0`.
